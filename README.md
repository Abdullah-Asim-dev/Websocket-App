
# 💬 Real-Time Chat Application

A modern full-stack real-time chat application built with **React, Node.js, Express.js, Socket.IO, and MongoDB**. The application provides secure authentication, instant messaging, persistent chat history, file sharing, emoji reactions, reply support, and a responsive user interface.

**React • Tailwind CSS • Framer Motion • Socket.IO • Express.js • MongoDB**

---

# 🌐 Live Demo

**Frontend:** https://gleaming-fairy-e0fcdc.netlify.app/

**Backend:** https://websocket-app-3.onrender.com

---

# ✨ Features

* 🔐 Secure User Authentication (JWT)
* 💬 Real-Time Messaging with Socket.IO
* 👥 Chat Rooms
* 🟢 Online User Tracking
* ⌨️ Live Typing Indicator
* 😊 Emoji Picker
* ❤️ Message Reactions
* ↩️ Reply to Messages
* 🗑️ Delete Messages
* 📎 File Sharing
* 🖼️ Image Sharing
* 💾 Persistent Chat History (MongoDB)
* 🌙 Dark & Light Theme
* 📱 Responsive User Interface
* ✨ Smooth Animations with Framer Motion

---

# ⚙️ Installation

## Clone Repository

```bash
gh repo clone Abdullah-Asim-dev/websocket-app
```

## Install Frontend

```bash
cd Frontend
npm install
npm run dev
```

## Install Backend

```bash
cd Backend
npm install
npm start
```
